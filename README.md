# 课堂同传（iPad 本机版）

只用 iPad 就能上课同传：老师说韩语，iPad 实时出中文字幕。识别、翻译、概括都在 iPad 本机完成。

- **免费**：只用苹果系统自带的离线识别和离线翻译。没有接口密钥，没有服务器，也没有免费额度，所以永远不会突然要钱。
- **不联网**：第一次用的时候下载一次语言包（要连 Wi-Fi），之后上课可以开飞行模式。
- **不上传**：声音和文字只存在这台 iPad 上。

这个分支只放 iPad App。它和 `main` 分支、网站都没有关系。

## 装到 iPad 上（不需要 Mac，也不需要付费开发者账号）

1. 在 iPad 的 App Store 安装苹果免费的 **Swift Playgrounds**。
2. 用 iPad 的 Safari 打开 <https://github.com/yuxian695-alt/-/archive/refs/heads/ipad-interpreter.zip> 下载这个分支（或者把电脑上的 `课堂同传.swiftpm.zip` 用微信、邮件发到 iPad，存到“文件”）。
3. 在 iPad 的“文件”App 里点一下 zip 解压，再点里面的 `ClassInterpreter.swiftpm`，Swift Playgrounds 会自动打开。
4. 点右上角的 ▶︎ 运行。第一次运行时，在弹窗里允许 **麦克风** 和 **语音识别**。
5. 在首页“上课前检查”里，把“语音识别”和“翻译”两项都点“下载”。翻译会弹出系统下载窗口，点“下载”就行。三项都显示绿色勾以后，就可以完全离线使用。

以后每次上课，打开 Swift Playgrounds，点开“课堂同传”，再点 ▶︎ 运行就行。

**更新到新版本**：在 Swift Playgrounds 的项目列表里长按旧的“课堂同传”→ 删除，再按上面第 2、3 步重新下载、打开。删之前先把需要的课堂记录“导出”保存一份。

## 上课

- 首页选好语言方向（韩语 → 中文等）和课程，点 **开始上课**。
- 屏幕上半部分是一句一句的双语字幕，下面的大字是老师 **正在说** 的话：老师还没说完，中文就会先出来，说完以后再定稿。
- 点一句字幕可以加星标。字号可以在顶部调。上课时屏幕不会自动锁定。
- 顶部会显示实测延迟，也就是“老师说完这句 → 中文出现”的中位数。
- 下课点 **结束**，App 会自动保存，并打开这节课的记录。

## 课后

- 点任意一句字幕，就从那里开始回听录音，可以 0.75～1.5 倍速播放。
- 可以搜索、只看星标句，也可以写笔记。
- 系统开着 Apple 智能的话，可以用 **本机 AI** 概括整节课，或者解释某一句。
- **导出** 字幕（Markdown 双语稿）和录音：可以存到“文件”，或者发到电脑上交给小霸王学习机精翻。
- 改了课程术语表以后，可以“用最新术语表全部重译”。

## 课程术语表

在首页点“课程和术语”，每门课一张表，一行写一条：`수요=需求`。

- 识别时，原文词会作为提示交给识别引擎，专业词更容易认对。
- 翻译前，原文词会先换成你指定的中文，这样译名前后一致。

## 用了哪些苹果技术

| 环节 | iPadOS 26 及以上（你的 iPad 是 27.2.1） | 更老的系统 |
|---|---|---|
| 识别 | SpeechAnalyzer / SpeechTranscriber，为讲座这类长语音设计，本机运行 | SFSpeechRecognizer 本机识别 |
| 翻译 | Translation 框架，本机运行 | 同左（iPadOS 18 起） |
| 概括 | Foundation Models（Apple 智能本机模型） | 不可用 |

录音是 16 kHz 单声道 AAC，每 5 分钟存一段。就算 App 中途被关掉，也最多丢最后几分钟；下课后会自动合并成一个文件。

## 实测（GitHub 的 Mac，合成韩语讲课，按真实速度播放）

| 指标 | 结果 |
|---|---|
| 老师说完一句 → 屏幕上“正在说”跟上 | 中位数 0.15 秒，最慢 0.45 秒 |
| 老师说完一句 → 这句定下来去翻译 | 中位数 1.40 秒，最慢 1.54 秒（只等引擎自己定稿要 14～30 秒） |
| 识别错字率（按字） | 4.3% |

GitHub 的虚拟机不支持新版 SpeechTranscriber，只能测上一代 DictationTranscriber。iPad 上用的是新版。苹果翻译在虚拟机上装不了语言包，所以没测；App 上课时会在顶部显示每句话的实测延迟。

## 准确度说明

苹果的离线翻译速度很快，但遇到长难句、敬语和专业内容时，不如电脑上的大模型准。上课时用 iPad 版保证跟得上；需要精确译文时，把录音导出给电脑上的小霸王学习机重新精翻。

## 开发者

- `ClassInterpreter.swiftpm/`：iPad App 本体（Swift Playgrounds 工程）。
- `Package.swift`、`Tests/`：在电脑或 CI 上测试纯逻辑，包括切句、术语表、去重复和自动增益。
- `ci/typecheck-app.sh`：把全部源码按 iPadOS 编译一遍。
- `Bench/`：在 GitHub 的 Mac 上，用韩语合成语音按真实速度测试苹果离线识别的延迟和错字率。
- `.github/workflows/ipad-app.yml`：每次推送都会自动跑上面这些检查。
